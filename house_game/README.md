# 禅庭 · zen-garden

> 一座可以走走进的日式枯山水庭院。

浏览器里跑的 Three.js 实时场景：白砂、石组、五重宝塔、盘旋的青龙，还有耙砂的僧人、蹲踞茶庭、屋脊上的猫。四个季节、四种天气、一整套可交互的器物，全部程序化生成——没有模型文件、没有贴图素材，**零构建、零依赖安装**。

## 快速开始

ES Module + importmap，**必须经 HTTP 打开**（`file://` 会被 CORS 拦下）：

```bash
cd house_game
python -m http.server 8000     # 或 npx serve . / php -S localhost:8000
```

然后访问 <http://localhost:8000/>。

没有 `npm install`，没有打包步骤。`three` 与 `three/addons/` 由 importmap 指向 jsDelivr CDN，改版本号只需动 `index.html` 里的一行。

环境要求：支持 WebGL2 + importmap 的现代浏览器（Chrome/Edge 89+、Firefox 108+、Safari 16.4+）。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 拖拽 / 滚轮 | 环视、缩放 |
| 点白砂 | 投下石子，泛起同心涟漪 |
| 开「耙砂」后在白砂上拖动 | 耙出砂纹（耙砂僧会跟着一起耙） |
| 点宝塔 | 撞响该层风铃；夜里偶尔自鸣 |
| 点青龙 | 龙吟喷火，点龙珠让它追珠 |
| 点石灯笼 | 点亮 / 熄灭 |
| 点鹿威・蹲踞 | 竹管流水与石钵 |
| 点小人、猫、樱、枫、松 | 各有台词与动作反馈 |
| 右上角 / `1`–`4` | 切换四季：春樱 · 夏雨 · 秋枫 · 冬雪 |
| `N` | 昼夜切换（灯笼自动点亮） |
| `R` | 耙砂模式开关 |
| `F` | 跟随青龙飞行 |

URL hash 可直达季节：`#spring` `#summer` `#autumn` `#winter`。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 渲染 | Three.js 0.170（WebGLRenderer、ACESFilmic、PCFSoft 阴影） |
| 相机控制 | OrbitControls（含阻尼、环游、跟随模式） |

| 模块 | 原生 ESM，无打包器 |

## 模块结构

14 个模块，每个只负责一件事，通过一个共享的 `ctx` 上下文协作：

```text
house_game/
├─ index.html          # UI 骨架 + importmap + 全部 CSS
└─ js/
   ├─ main.js          # 入口：装配模块、拾取交互、UI、主循环
   ├─ util.js          # 数学/材质/岩石几何/文字精灵等底层工具
   ├─ scenery.js       # 天空穹顶、日月、星辰、萤火、远山借景、流云
   ├─ sand.js          # 白砂床：高度图刻槽、耙砂笔触、涟漪
   ├─ garden.js        # 地面、石垣、缘侧、汀步、庭院布局常量
   ├─ plants.js        # 庭松、竹林、枝垂樱、枫树、落瓣粒子
   ├─ props.js         # 石灯笼、鹿威・蹲踞茶庭
   ├─ pagoda.js        # 五重塔：破面屋顶、斗栱、相轮、风铃
   ├─ dragon.js        # 青龙：脊线扫掠、龙鳞贴图、龙首、飞行 AI
   ├─ people.js        # 耙砂僧、茶人、游客、屋顶猫
   ├─ seasons.js       # 四季预设、环境插值、积雪 shader patch
   ├─ weather.js       # 雨、溅水圈、雪、闪电与雷声
   └─ audio.js         # Sfx：钟、磬、鹿威、水声、雨、雷…
```

装配顺序有讲究：`createSeasons()` 放在最后，因为切季时要回头 patch 场景里所有已存在的材质。

## 实现要点

<details>
<summary><b>砂纹即高度图</b></summary>

白砂是一张 2000×1200 的 Canvas（50 px/世界单位），耙砂笔触往里画余弦剖面的平行沟槽，这张图作为 `bumpMap` 驱动砂面。沟槽周期 0.25、半宽 0.5，`2×halfWidth` 是周期的整数倍，所以笔触能无缝平铺。拖动时只重绘笔迹尾部的一小段窗口，不是全图重画。投石涟漪是"擦除前沿 + 同心沟槽向外生长"，带 0.14 单位的视觉滞后，看起来像沙粒被推着走。

</details>

<details>
<summary><b>塔顶破面屋顶</b></summary>

五重塔的屋顶不是圆锥，而是按解析曲面生成的：给定径向比例 t 和横向 s，屋面高度随 t 凹进去（sōki 的反宇），四角起翘。上一层塔身正好落在下层屋面与墙身的交界处。

</details>

<details>
<summary><b>龙的脊线</b></summary>

沿一条 90 点、弧长等分的脊线扫掠管体，逐点缩放半径做出从颈到尾的收分；腹部用生成的鳞片贴图叠一层，四爪与背鳍单独建模。飞行是"惰性游荡"：在几个兴趣点（宝塔、樱树、后山松）之间做缓动飞越，会抬升高度避开塔顶。

</details>

<details>
<summary><b>四季是环境插值，不是四套场景</b></summary>

每个季节预设只声明树冠配色、落叶量、天气强度和一组环境色，天空/雾/光照/积雪全部按 `dt` 插值过渡。积雪通过 `onBeforeCompile` 给材质加 `uSnow`，按法线朝上的程度提亮——并且正确扩展了 `customProgramCacheKey`，避免打了补丁和没打补丁的变体共用同一个 shader program。

</details>

<details>
<summary><b>声音全是算出来的</b></summary>

钟是非谐分音叠加，磬带合成的混响尾，雨是循环噪声过带通滤波按强度淡入。整包没有一个音频文件。

</details>

<details>
<summary><b>拾取要跟砂面比距离</b></summary>

交互物和砂面同时被射线命中时，只有比砂面更近的那个才算数——否则埋在沙里的石组底座会抢走点击。耙砂笔迹用捕获阶段监听 `pointerdown`，赶在 OrbitControls 之前禁用相机控制。

</details>

## 已知限制

- 需要联网加载 Three.js CDN；离线环境请把 three 落到本地再改 importmap
- 移动端可用（做了响应式布局），但未针对触屏优化耙砂手感
- 阴影贴图在低端设备上可能掉帧，可在 `main.js` 里调 `shadowMap` 尺寸
